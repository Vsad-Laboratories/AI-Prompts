# Reasoning Prompt: Decision Tree Logic & Edge Case Evaluator

## Purpose
Systematically map complex conditional logic, business rules, or policy decisions into formal decision trees, identifying hidden logical gaps, unreachable branches, and unhandled edge cases.

## Inputs
- `BUSINESS_RULES`: Description of policies, eligibility requirements, or decision logic.
- `INPUT_VARIABLES`: Allowed values, data types, and boundary ranges for decision inputs.
- `EXPECTED_OUTCOMES`: Target terminal states or outputs generated by the logic.

## Instructions
1. Deconstruct `BUSINESS_RULES` into a sequential, Boolean decision tree structure (`IF-THEN-ELSE`).
2. Map every unique path from root node to terminal leaf nodes, ensuring every input combination produces a valid terminal outcome.
3. Perform a **Logical Completeness Audit**:
   - Detect **Dead/Unreachable Logic Branches**: Conditions that can never evaluate to true given prior branch constraints.
   - Detect **Unhandled Combinations (Gaps)**: Variable value permutations where no explicit business rule applies.
   - Detect **Ambiguous/Conflicting Rules**: Scenarios where multiple rules trigger contradictory outcomes.
4. Construct a formal Truth Table matrix validating all variable state combinations.
5. Formulate corrected business logic definitions resolving all flagged edge cases.

## Constraints
- Ensure coverage of extreme boundary conditions (e.g., zero values, null inputs, maximum limits, simultaneous true states).
- Avoid vague fallback rules that mask underlying specification gaps.

## Expected output
- **Decision Tree Node Map**: Hierarchical representation of decision logic.
- **Exhaustive Truth Table**: Matrix mapping input permutations to outcomes.
- **Logical Gap & Edge Case Report**: Identified dead branches, conflicts, or unhandled conditions.
- **Refactored Business Logic Specification**: Complete, gap-free rule definition.
