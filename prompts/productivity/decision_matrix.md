# Productivity Prompt: Decision Matrix and Action Planner

## Purpose
Resolve decision paralysis or prioritisation confusion when facing multiple competing, high-stakes options or tasks.

## Inputs
- `OPTIONS_OR_TASKS`: The set of decisions, ideas, or projects being considered.
- `EVALUATION_CRITERIA`: Core factors to weigh (e.g., cost, effort, alignment with long-term goals, risk).

## Instructions
1. Review the `OPTIONS_OR_TASKS` and `EVALUATION_CRITERIA`.
2. Construct a **Weighted Decision Matrix**:
   - Assign a weight (1-5) to each criterion based on current strategic priorities.
   - Score each option/task from 1 to 10 on each criterion.
   - Calculate the total weighted score for each option.
3. Group the options/tasks using an **Eisenhower Matrix** (Urgent & Important, Important but Not Urgent, Urgent but Not Important, Neither).
4. Outline a 2-step immediate action plan for the winning option to overcome friction and build momentum.

## Constraints
- Scores and weights must be logically consistent; do not manipulate numbers to fit a pre-conceived favorite option.
- Ensure the criteria weights sum to a standardized baseline if applicable.

## Expected output
- **Weighted Scoring Table**: Complete matrix with weighted totals.
- **Eisenhower Quad Mapping**: Visual representation or list mapping options to the four quadrants.
- **Immediate Action Roadmap**: Clear definition of the top option and the absolute first physical step to take next.
