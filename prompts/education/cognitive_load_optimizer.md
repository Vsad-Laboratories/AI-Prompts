# Education Prompt: Educational Instructional Design & Cognitive Load Optimizer

## Purpose
Optimize educational technical documentation, tutorials, and course materials to minimize extraneous cognitive load and maximize working memory efficiency for learners.

## Inputs
- `DRAFT_LESSON_CONTENT`: Raw technical tutorial, textbook chapter, or complex documentation draft.
- `TARGET_AUDIENCE`: Prerequisite knowledge level of intended readers.

## Instructions
1. Analyze `DRAFT_LESSON_CONTENT` for Cognitive Overload triggers: Split-Attention Effect, Redundancy Effect, and Expertise Reversal Effect.
2. Restructure content according to Sweller's Cognitive Load Theory: reduce extraneous load, optimize intrinsic load, and foster germane load.
3. Apply chunking, dual-coding (text + visual layout structure), and worked-example scaffolding.
4. Convert dense text walls into progressive discovery steps with interactive mental check-ins.
5. Provide a refactored version of the lesson optimized for accelerated mental model formation.

## Constraints
- Preserve full technical accuracy while simplifying visual presentation and readability.
- Do not omit essential technical details; scaffold them progressively instead.

## Expected output
- **Cognitive Load Audit**: Analysis identifying split-attention points and extraneous complexity.
- **Instructional Scaffolding Plan**: Step-by-step layout design and visual framing notes.
- **Optimized Educational Content**: Fully refactored, highly readable learning module.
