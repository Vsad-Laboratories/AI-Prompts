# Writing Prompt: UX Content Strategy Audit

## Purpose
Audit an entire website, product module, or set of user-facing communications to assess terminology consistency, brand voice compliance, and user comprehension.

## Inputs
- `UX_COPY_SAMPLES`: A collection of buttons, error screens, emails, and landing page texts.
- `BRAND_VOICE_GUIDELINES`: Core principles (e.g., authoritative but friendly, transparent, direct).

## Instructions
1. Analyze the `UX_COPY_SAMPLES` to evaluate clarity, consistency, and alignment with the `BRAND_VOICE_GUIDELINES`.
2. Map terminology across the samples: Identify any synonyms or conflicting terms for the same concept (e.g., calling a feature a "dashboard" in one screen and a "control panel" in another).
3. Create a **Voice and Tone Compliance Scorecard**: Score readability, technical jargon, accessibility, and emotional appropriateness.
4. Rewrite the non-compliant samples into clean, standardized, and brand-consistent UX copy.
5. Create a basic **UX Writing Style Rulebook** based on the findings to prevent future consistency issues.

## Constraints
- Align all recommendations with accessibility guidelines (e.g., clear, descriptive links rather than generic "click here").
- Ensure the character constraints of the original UI elements are respected in the rewrites.

## Expected output
- **Terminology Inconsistency Log**: Table detailing current terms, issues, and standardized recommendations.
- **Compliance Scorecard**: Analytical evaluation of the audited copy.
- **Before-and-After Board**: Comparative list of non-compliant and optimized copy blocks.
- **UX Writing Cheat Sheet**: 5 core rules for future content creators on the team.
